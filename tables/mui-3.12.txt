# Modern UI 2, as its own headers read it.
#
# Columns: what the name is, the name, what MUI2's text does with it, where it
# is first seen, and the `!macro` that line sits in. Regenerate with:
#
#     cargo run -q -- mui "$NSISDIR" > tables/mui-3.12.txt
#
# Tags, each a fact about the text and none of them a judgement:
#
#   default  MUI2 supplies one through `MUI_DEFAULT`, so leaving it out is legal
#   page     MUI2 `!undef`s or `MUI_UNSET`s it, so it is read once per page
#   once     it is read inside an `!ifndef`-guarded `*_INTERFACE` macro, so the
#            first page of its type wins and every later one is ignored
#   set      MUI2 writes it itself somewhere, so a row may be its state and not
#            a setting at all
#   un       MUI2 builds the name with its uninstaller prefix, so `MUI_UN…`
#            exists too and is the same setting for the other half
#   doc      MUI2's own Readme.html names it, which is the only place that says
#            whether a define is yours to write or MUI2's to keep
#
# Not read: Deprecated.nsh, whose every macro is a `!error` MUI2 raises on
# purpose. Naming one in Installua would be an Installua spelling for a
# thing MUI2 refuses to compile:
#
#   MUI_INSTALLOPTIONS_DISPLAY
#   MUI_INSTALLOPTIONS_DISPLAY_RETURN
#   MUI_INSTALLOPTIONS_EXTRACT
#   MUI_INSTALLOPTIONS_EXTRACT_AS
#   MUI_INSTALLOPTIONS_INITDIALOG
#   MUI_INSTALLOPTIONS_READ
#   MUI_INSTALLOPTIONS_SHOW
#   MUI_INSTALLOPTIONS_SHOW_RETURN
#   MUI_INSTALLOPTIONS_WRITE
#   MUI_LEGACY_MAP_NOSTRETCH
#   MUI_RESERVEFILE_INSTALLOPTIONS
#
# Names MUI2 builds out of a macro argument. Each is derived from a name
# already listed, so there is nothing here for a user to write:
#
#   MUI_HEADERIMAGE_BITMAP${RTL}_STRETCH
#   MUI_PAGE_CUSTOMFUNCTION_${TYPE}
#   MUI_STARTMENUPAGE_${ID}_DEFAULTFOLDER
#   MUI_STARTMENUPAGE_${ID}_REGISTRY_KEY
#   MUI_STARTMENUPAGE_${ID}_REGISTRY_ROOT

#   MUI_STARTMENUPAGE_${MUI_STARTMENUPAGE_CURRENT_ID}_REGISTRY_ROOT
