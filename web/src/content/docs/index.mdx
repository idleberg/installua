## Installua at a glance

```lua
attributes {
	name = "MyApp",
	outFile = "MyApp-setup.exe",
	compressor = "lzma",
}

installer {
	installDir = PROGRAMFILES64 .. "/MyApp",

	page.welcome {},
	page.directory {},
	page.instFiles {},
	page.finish {},

	section("Core", function()
		setOutPath(INSTDIR)
		file("myapp.exe")
		writeUninstaller(INSTDIR .. "/uninstall.exe")
	end),
}
```
